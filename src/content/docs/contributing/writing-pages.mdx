Every page is a Markdown (`.md`) or MDX (`.mdx`) file in `src/content/docs/`. The folder decides which sidebar section it lands in, and the file name becomes the URL.

## Adding a page

<Steps>

1. Pick the section folder, for example `src/content/docs/factions/`.

2. Create a file such as `piglins.md` with this frontmatter:

   ```md
   ---
   title: Piglins
   description: Units, buildings and strategy for the Piglin faction.
   sidebar:
     order: 3 # optional: lower numbers appear first
   ---

   Your content here.
   ```

3. Run `pnpm dev` and open the page at `/factions/piglins/`.

</Steps>

<FileTree>
- src/content/docs/
  - index.mdx home page
  - getting-started/
  - launcher/
  - factions/
    - index.md section overview
    - **piglins.md** your new page
  - game-modes/
  - multiplayer/
  - mapmaking/
  - contributing/
</FileTree>

To add a whole new sidebar section, create the folder and add it to `sidebar` in `astro.config.mjs`.

## Images

Put images next to your page, or in `src/assets/`, and link them relatively. They're rendered pixelated, which suits Minecraft textures.

```md
![Piglin Brute](../../assets/piglin-brute.png)
```

## Callouts

Use `:::note`, `:::tip`, `:::caution` or `:::danger` in Markdown:

:::note
Notes add context.
:::

:::tip[Pro tip]
Tips can have a custom title.
:::

:::caution
Cautions warn about mistakes.
:::

:::danger
Dangers warn about losing progress or data.
:::
